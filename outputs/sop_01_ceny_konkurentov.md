# SOP-01. Как собрать цены конкурентов по товару

**Это пошаговая инструкция на одну задачу.** Не нужно ничего «придумывать» и
анализировать — просто идите по шагам сверху вниз и заполняйте таблицу. Если
дошли до конца и таблица заполнена — задача сделана правильно.

**Что на выходе должно получиться:** заполненная таблица цен конкурентов + одна
строка вывода «мы дороже/дешевле на столько-то». Образец — в конце (раздел 5).

**Сначала определите тип товара и идите в свою ветку:**
- Корейская косметика → **Раздел A**
- Судовое оборудование → **Раздел B**
- Общие правила сравнения (для обоих) → **Раздел 3**
- Самопроверка перед сдачей → **Раздел 4**

Дата: __________  Кто заполнял: __________  Какой товар анализируем: __________

## Раздел A. Косметика (цены на Wildberries)

### Шаг A1. Запишите наш товар
Откройте карточку нашего товара и выпишите:
- Бренд: __________
- Название: __________
- Объём (мл/г): __________
- Наша цена (та, что видит покупатель, крупная/зелёная): __________ ₽
- Артикул: __________

### Шаг A2. Придумайте 2–3 запроса, как ищет покупатель
Не бренд, а «что это за товар». Примеры: «крем для лица с муцином улитки»,
«корейский увлажняющий крем 50 мл».
- Запрос 1: __________
- Запрос 2: __________
- Запрос 3: __________

### Шаг A3. Найдите конкурентов
1. Откройте Wildberries (сайт или приложение).
2. Введите Запрос 1 в строку поиска.
3. Из того, что выпало, возьмите **первые 5–7 карточек такого же типа товара**
   (та же категория и примерно тот же объём). Явно другое — пропускайте
   (другой тип, набор, пробник).

### Шаг A4. По каждому конкуренту выпишите в таблицу (Раздел 3)
- Бренд, Название, Объём (мл);
- **Цена** — берём ту, которую видит покупатель (крупная зелёная/итоговая цена
  с учётом скидки), **не** старую зачёркнутую;
- Рейтинг и число отзывов;
- Артикул и ссылку.

### Шаг A5. Если объёмы разные — посчитайте цену за 1 мл
`цена ÷ объём в мл`. Это чтобы сравнивать честно (50 мл и 100 мл иначе
сравнивать нельзя). Запишите в колонку «Цена за мл».

Дальше → **Раздел 3** (сравнение и вывод).

---

## Раздел B. Судовое оборудование (B2B, цены у поставщиков)

### Шаг B1. Точно определите товар
Главное здесь — **модель/артикул производителя (парт-номер)**. Одинаковый
парт-номер = тот же товар.
- Наименование: __________
- Производитель: __________
- Модель / артикул (парт-номер): __________
- Ключевые характеристики (что важно): __________
- Новое или б/у: __________
- Наша цена: __________ ₽ (с НДС / без НДС — нужное подчеркнуть)

### Шаг B2. Найдите 3–5 продавцов
1. Введите **парт-номер** в поиск (Яндекс/Google).
2. Смотрите: сайты поставщиков судового оборудования, прайсы, маркетплейсы,
   объявления. Берите только тот же парт-номер (или явный аналог — пометьте
   «аналог»).

### Шаг B3. По каждому продавцу выпишите в таблицу (Раздел 3)
- Продавец (компания/сайт);
- Цена и **с НДС или без** (это обязательно уточнить!);
- Новое/б/у, оригинал/аналог;
- Наличие и срок поставки;
- Минимальная партия;
- Ссылка/контакт.

### Шаг B4. Если цены на сайте нет — запросите КП
Напишите продавцу короткое письмо-запрос (шаблон):
> «Здравствуйте! Интересует [наименование, парт-номер], [кол-во] шт. Прошу
> сообщить цену (с НДС), наличие и срок поставки. Спасибо.»
Ответ впишите в таблицу.

Дальше → **Раздел 3** (сравнение и вывод).

## Раздел 3. Таблица и вывод (для обеих веток)

### Золотые правила сравнения (чтобы не ошибиться)
1. Сравнивайте **одинаковое с одинаковым**: тот же объём / та же модель, та же
   комплектация.
2. Цены приводите к одному виду: косметика — цена покупателя (с СПП); оборудование
   — **все с НДС** (или все без), как удобнее, но одинаково по всем.
3. Берите **актуальную цену на сегодня**, не старую.
4. Не угадывайте: если чего-то не знаете — ставьте прочерк и пометку «уточнить»,
   не выдумывайте число.

### Таблица (заполните)

| № | Конкурент/Продавец | Товар (бренд/модель) | Объём/комплектация | Цена, ₽ | С НДС? (для оборуд.) | Цена за мл (для косметики) | Наличие/рейтинг | Ссылка |
|---|--------------------|----------------------|--------------------|---------|----------------------|----------------------------|-----------------|--------|
| 1 |  |  |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |  |  |
| 3 |  |  |  |  |  |  |  |  |
| 4 |  |  |  |  |  |  |  |  |
| 5 |  |  |  |  |  |  |  |  |

### Посчитайте 3 числа по колонке «Цена»
- Минимальная цена у конкурентов: __________ ₽
- Средняя цена (сложить все цены и разделить на их количество): __________ ₽
- Максимальная цена у конкурентов: __________ ₽

### Вывод одной строкой (выберите нужное и впишите числа)
- Наша цена __________ ₽. Это **дороже / дешевле / на уровне** конкурентов.
- Мы **дороже/дешевле средней на __________ %**
  (разница ÷ средняя × 100).
- Короткий вывод: ______________________________________________________

## Раздел 4. Самопроверка перед сдачей (обязательно)

Отметьте галочками. Сдавать можно, только когда все галочки стоят:

- ☐ В таблице минимум 3 конкурента (лучше 5).
- ☐ Все цены — актуальные и в одном виде (косметика с СПП / оборудование все с НДС).
- ☐ Сравниваю одинаковый объём/модель (или посчитал цену за мл).
- ☐ Посчитаны мин / средняя / макс.
- ☐ Есть вывод одной строкой с процентом разницы.
- ☐ Нигде не выдумал число: где не знаю — прочерк и «уточнить».
- ☐ Все ссылки/контакты вставлены (можно проверить).

Если хоть одна галочка не стоит — вернуться и доделать, **не сдавать**.

## Раздел 5. Образец «как выглядит правильно» (пример для косметики)

Наш товар: крем с муцином улитки, 50 мл, наша цена 690 ₽.

| № | Конкурент | Товар | Объём | Цена | Цена за мл | Рейтинг | Ссылка |
|---|-----------|-------|-------|------|-----------|---------|--------|
| 1 | Бренд A | Крем с муцином | 50 мл | 590 ₽ | 11,8 ₽ | 4,8 (2100) | ссылка |
| 2 | Бренд B | Крем улитка | 50 мл | 650 ₽ | 13,0 ₽ | 4,7 (880) | ссылка |
| 3 | Бренд C | Snail крем | 60 мл | 790 ₽ | 13,2 ₽ | 4,9 (5400) | ссылка |

- Мин: 590 ₽, Средняя: 677 ₽, Макс: 790 ₽.
- Наша цена 690 ₽ — **чуть дороже средней на ~2%** (690−677=13; 13÷677≈2%).
- Вывод: мы в рынке, чуть выше середины. Можно не трогать цену, но у Бренда A
  дешевле и много отзывов — последить за ним.

Вот так же заполняется и по судовому оборудованию, только вместо «цена за мл» —
колонка «с НДС / без НДС» и «срок поставки».
