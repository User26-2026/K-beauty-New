# Рабочий тест-ассессмент менеджера

**Назначение:** честно и объективно проверить, может ли сотрудник выполнять
рабочие задачи и при каких условиях. Это **не психологический тест и не
диагноз** — только работа и результат. Решение принимается по заполненным
бланкам, а не по догадкам.

**Логика:** три задачи по нарастанию самостоятельности.
- Задача 1 — исполнение по готовой инструкции (минимум самостоятельности).
- Задача 2 — работа с цифрами по образцу (нужно применить формулу).
- Задача 3 — маленький самостоятельный вывод по готовому правилу.

Где сотрудник «отваливается», там и граница его зоны. Это и есть ответ на
вопрос «что ему можно поручать».

---

## Инструкция для проверяющего (прочитать до начала)

1. Выделите спокойное время, 60–90 минут, без спешки.
2. Дайте задачи **по одной**, по порядку. Разрешено пользоваться материалами
   (SOP-01, калькулятор, интернет).
3. **Не подсказывайте и не делайте за сотрудника.** Если сотрудник просит
   помощь — не отказывайте, но **отметьте в бланке**, сколько раз и на каком
   шаге понадобилась помощь. Это и есть измерение.
4. Отмечайте примерное время на задачу и число вопросов «а как?».
5. Ответы для проверки (что считать правильным) — в конце, в разделе
   «КЛЮЧ ПРОВЕРЯЮЩЕГО». **Сотруднику его заранее не показывать.**

# ЗАДАЧА 1. Собрать цены конкурентов по инструкции

**Что сделать:** взять один наш товar (назовите какой: __________) и по
инструкции **SOP-01 «Как собрать цены конкурентов»** заполнить таблицу и
сделать вывод.

**Что сдать:** заполненную таблицу SOP-01 (минимум 3 конкурента), числа
мин/средняя/макс и вывод одной строкой.

Отметки проверяющего:
- Время: ______ мин   Вопросов «а как?»: ______   Просила помощь: ______ раз

Критерии (отметьте выполнено/нет):
- ☐ Заполнено ≥3 конкурента
- ☐ Взята правильная цена (косметика — с СПП; оборуд. — с пометкой НДС)
- ☐ Сравнивается одинаковый объём/модель (или посчитана цена за мл)
- ☐ Посчитаны мин/средняя/макс
- ☐ Есть вывод одной строкой
- ☐ Нет выдуманных чисел (где не знает — прочерк)

# ЗАДАЧА 2. Посчитать прибыль по образцу

**Что сделать:** в таблице ниже посчитать по каждому товару **маржу** и
**маржу в %**, затем отметить **самый прибыльный** товар.

**Формулы (даны):**
- Маржа, ₽ = Цена − Себестоимость
- Маржа, % = Маржа ₽ ÷ Цена × 100

**Образец (строка А уже посчитана):**
Товар А: 690 − 300 = **390 ₽**; 390 ÷ 690 × 100 = **56,5%**.

| Б | 590 | 350 |  |  |

# ЗАДАЧА 3. Принять простое решение по правилу

**Что сделать:** по каждому товару принять решение, пользуясь **готовым
правилом**.

**Правило (дано):**
- Если ДРР **ниже 10%** → написать «усилить».
- Если ДРР **выше 25%** → написать «на паузу».
- В остальных случаях → написать «оставить».

Заполните колонку «Решение»:

| Товар 2 | 25 | 31% |  |
| Товар 3 | 18 | 15% |  |

Одной строкой: какой товар сейчас важнее всего и почему?
______________________________________________________________________

Отметки проверяющего:
- Время: ______ мин   Вопросов «а как?»: ______   Просила помощь: ______ раз

Критерии:
- ☐ Все три решения по правилу — верные
- ☐ Вывод одной строкой осмысленный (не противоречит правилу)
- ☐ Справилась без пошаговой диктовки

# КАК ЧИТАТЬ РЕЗУЛЬТАТ (для руководителя)

- **Все три «справляется»** → может работать достаточно самостоятельно.
  Давать структурированные задачи, зону ответственности расширять постепенно.
- **Задача 1 — ок, задачи 2–3 — слабо** → это **исполнитель**. Держать строго
  на SOP/чек-листах, не поручать расчёты и решения без готового образца и
  правила. Это рабочий вариант, просто роль узкая.
- **Задача 1 слабо даже по SOP** (ошибки по готовой пошаговой инструкции) →
  **несоответствие роли**. Варианты: сузить до простейших повторяемых операций
  под контролем, либо честно обсудить другую роль/расставание.
- **Много «с поддержкой» и много вопросов «а как?»** → сотрудник не держит
  задачу сам; автономию давать нельзя, работа — только по инструкции с точкой
  проверки.

**Важно:** решение принимается по этим бланкам (объективный результат), а не по
предположениям о характере или здоровье. Если есть реальная тревога именно за
здоровье — это отдельно и к профильному специалисту, не через рабочий тест.

# КЛЮЧ ПРОВЕРЯЮЩЕГО (не показывать сотруднику заранее)

**Задача 2 — правильные ответы:**
| Товар | Маржа, ₽ | Маржа, % |
|-------|----------|----------|
| Б | 240 | 40,7% |
| В | 700 | 58,3% |
| Г | 200 | 44,4% |
| Д | 200 | 25,0% |

Самый прибыльный по марже в ₽ — **товар В (700 ₽)**. (По % тоже В — 58,3%.)

**Задача 3 — правильные ответы:**
- Товар 1 (ДРР 7%, ниже 10%) → **усилить**
- Товар 2 (ДРР 31%, выше 25%) → **на паузу**
- Товар 3 (ДРР 15%, между) → **оставить**
Осмысленный вывод: важнее всего Товар 1 — он эффективен (низкий ДРР) и его
стоит усиливать; либо Товар 2 — как проблемный, его надо тормозить. Оба ответа
засчитываются, если не противоречат правилу.

**Задача 1 — что считать правильным:** см. критерии задачи 1 и образец в
разделе 5 инструкции SOP-01.
