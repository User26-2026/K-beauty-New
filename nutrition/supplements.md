# БАДы (добавки)

Принимаемые добавки. **Важно:** у пользователя врождённая единственная почка —
минеральные добавки и аминокислоты должны быть согласованы с нефрологом.
На калории/БЖУ дня не влияют, в дневник по калориям не заносятся.

|---|---|---|
| ORIHIRO Глюкозамин (глюкозамина гидрохлорид) | 1500 мг/сут (10 табл.) | Из ракообразных (аллерген). Осторожно при приёме антикоагулянтов (написано на банке). Данных по почкам мало — обсудить с врачом. |
| ~~Solgar Zinc 50 мг~~ | **ОТМЕНЁН** (14.07) | Отменён из-за зуда после приёма (возможна реакция/непереносимость). Доза 50 мг и так выше предела 40 мг. Если понадобится — только короткий курс 15–25 мг по назначению врача. При нарастании сыпи/отёка/затруднении дыхания — срочно к врачу. |
| Solgar Chelated Magnesium | по этикетке | Магний выводится почками. При снижении функции почки может накапливаться (гипермагниемия). Держать на контроле у нефролога. |

| ~~Isostar Hydrate & Perform (изотоник)~~ | **НЕ пьёт** | Есть в наличии, но не употребляет — правильно (лишний сахар + калий, при сидячем режиме не нужен). В дневник по калориям не заносится. |

## Не еда (наружное, не считаем)

- Крем для рук и ногтей Hand & Nail (с коллагеном) — наружная косметика, в питание не входит.

## Что важно проверить с врачом

1. **Магний** — минерал, который регулирует почка. При нормальной функции ок, с одной почкой держать под контролем (анализы).
2. **L-аргинин** — добавляет к белковой/азотистой нагрузке; для похудения/спины бесполезен; кандидат на отмену.
3. Показать нефрологу оставшийся список — оценить суммарную нагрузку.

**Не принимает:** креатин, изотоник Isostar (правильно), **цинк 50 мг (отменён 14.07 из-за зуда)**.
