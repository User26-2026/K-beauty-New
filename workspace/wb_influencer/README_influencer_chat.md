# Рабочий чат: Анализ блогеров / внешний трафик (Wildberries, K-beauty)

Ветка: `claude/influencer-analysis`. Этот README — точка входа для отдельного чата по
эффективности продвижения через блогеров (TikTok, YouTube, Instagram, Telegram).

## Задача

Считать эффективность затрат на внешний трафик (блогеры) с привязкой к нашим товарам
и юнит-экономике: прогноз, отбор площадок, CPO/ДРР/ROMI, точка безубыточности,
калибровка по фактическим посевам.

## Данные

- `workspace/wb_influencer/bloggers_beauty_tiktok_youtube_2026-06.xlsx` — прайс площадок
  (TikTok 54, YouTube 18): прогноз просмотров, цена с НДС, CPV/CPM, гео/пол/возраст, формат.
- `workspace/wb_influencer/kbeauty_seeding_real_2026-05_06.xlsx` — ФАКТ посевов Инста/ТГ
  с подменными артикулами (точная атрибуция): стоимость, переходы, заказы, CPC, CPO.
  9 вкладок (7 с данными + 2 пустые «Отслеживание по артикулам»).
- `outputs/wb_influencer/blogger_efficiency_2026-06.tsv` — разметка 65 площадок
  (эфф.CPV, безуб.CR, ROMI, брать/тест/исключить).
- `workspace/wb_audit/wb_audit_summary.json` — экономика SKU кабинета (маржа/шт, конверсия,
  выкуп, цена) для выбора товара под продвижение.
- `tools/calc_unit.py` — расчёт юнитки (маржа/шт) по нашей логике.

## Методика (Вариант 2 + калибровка фактом)

Воронка: `просмотры × %РФ × %Ж → переходы (CTR) → заказы (CR) → выкуп → маржа/шт`.
Метрики: CPV, CPC, CPO, ДРР_внешний, ROMI, точка безубыточности.
Отбор площадок — по «эффективному CPV» (цена за целевой РФ-женский показ).

## Ключевые выводы (на 2026-06-09)

- ФАКТ посевов: бюджет 21 600 ₽, 232 перехода, 8 заказов → **CPC 93 ₽, CPO 2 700 ₽**.
  Все заказы принёс 1 блогер из 11 (CPO 438 ₽), остальные — 0. Это игра на попадание.
- Рекалибровка TikTok/YT (бюджет 3,23 млн ₽): при пул-CPO 2 700 ₽ ROMI −69…−89%.
  Окупаемость только при отборе блогеров уровня лучшего (CPO ≤ ~450 ₽) И марже SKU ≥ 450–850 ₽.
- Под блогеров брать ВЫСОКОМАРЖИНАЛЬНЫЕ SKU (сыворотки Manyo/Celimax 850–1420 ₽),
  не скраб/тон (маржа 300–365 ₽).
- Подменный артикул недосчитывает brand-uplift → реальный CPO ниже; мерить полный аплифт
  (продажи SKU + брендовый поиск в окне кампании).
