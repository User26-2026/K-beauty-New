## Актуальные правила WB, которые учтены

1. Прямая логистика сейчас считается по формуле с учетом базового тарифа, коэффициента склада, ИЛ и ИРП:  
   `логистика = базовый тариф * коэффициент склада * индекс локализации + цена до скидки WB * ИРП`

2. Актуальная база логистики WB: для товаров до 1 л тариф зависит от диапазона объема, для товаров больше 1 л — 46 ₽ за первый литр + 14 ₽ за каждый дополнительный литр.

3. ИРП обновляется еженедельно, считается по последним 13 неделям и при локальности от 60% становится 0%. Если локальность ниже 60%, логистика получает дополнительную надбавку от цены товара до скидки WB.

4. В рекламе WB поиск работает по кластерам. Исключение работает по кластеру, а не по одной фразе, поэтому перед минусацией нужно смотреть состав кластера и продажи.

## Главные риски

1. Файл себестоимости используем только как источник себестоимости. Фактическую прибыль нужно считать через отчет WB `Доходы и расходы`: `Итог, ₽ - себестоимость * чистые выкупы`; затем отдельно учитывать хранение и рекламу. ИРП/ИЛ учитывать как причину удорожания логистики.
2. Локальность 55,97% ниже порога 60%, значит ИРП может удорожать логистику.
3. Есть высокоспросовые SKU с нулевым остатком, особенно SPF.
4. Платное хранение уже 105 тыс. ₽ за неполный майский период.
5. Реклама анализируется пока только по одной кампании. Для полного рекламного аудита нужны все кампании.
6. В отчетах смешаны косметика и другие категории, надо подтвердить границы клиентского аудита.
