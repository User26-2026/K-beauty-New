# Рабочий чат: SEO по ключам (Wildberries, корейская косметика)

Этот README — точка входа для отдельного чата по SEO-кластерам. Ветка: `claude/seo-keywords`.

## Как формулировать запрос в чате

Скинь Excel-отчёт MP Manager по товару и напиши, например:
> «Проанализируй отчёт и выдай SEO по алгоритму из CLAUDE.md для товара <артикул/название>».

Если артикула нет — агент определит товар по брендовым/ингредиентным кластерам и/или
по нашим данным кабинета (`workspace/wb_audit/wb_audit_summary.json`).

## Алгоритм (полностью зафиксирован в корневом CLAUDE.md → раздел «SEO карточек»)

Кратко:
- Бренд НЕ выносим в SEO-название (только поле «Бренд» + описание).
- Название до 60 символов, главный товарный ключ из топа.
- Описание 900–1400 знаков, кластеры встроены в текст, без переспама.
- Кластер берём только под товар; не выдумываем ингредиенты, которых нет в составе.
- Группы кластеров: Both / Competitor / Your; в первую очередь Both и релевантные Competitor.
- Для каждого кластера указываем частотность/мес и заказы/мес.
- Формат ответа: 1) таблица кластеров, 2) «не использовать», 3) название ≤60,
  4) описание, 5) характеристики WB, 6) что перепроверить в MP Manager.

## Где что лежит

- `workspace/wb_search_serp/` — сырые выгрузки выдачи (`serp_*.xlsx`) и отчёты
  «Сравнение по кластеру» (`cluster_compare_*.xlsx`). Сюда же класть новые отчёты.
- `data/price_lists/` — прайсы брендов (KRW), для проверки состава/линейки.
- `data/stock_costs/` — себестоимость и остатки.
- `workspace/wb_audit/wb_audit_summary.json` — данные кабинета по SKU
  (название, бренд, цена, конверсия, выкуп) — помогает определить товар по артикулу.

## Правила сохранения

Каждый новый отчёт сохраняем в `workspace/wb_search_serp/` с понятным именем
(`cluster_compare_<артикул>_<дата>.xlsx` или `serp_<ключ>_<дата>.xlsx`),
коммитим и пушим в ветку `claude/seo-keywords`.
