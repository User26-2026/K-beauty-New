# Платформа автоматизации маркетплейсов (мультиклиент)

ИИ-движок на сервере ведёт магазины на WB/Ozon: **реклама, SEO, ценообразование, остатки/поставки**.
Мультиклиентная с нуля — твой магазин (Коротич) идёт первым клиентом (эталон, Этап 0),
новые клиенты добавляются одной записью в реестр.

## Архитектура

```
mp_platform/
  config.py            реестр клиентов + настройки платформы
  clients/
    clients.yaml       клиенты (в .gitignore), токены — через ${ENV}
  core/
    db.py              SQLite: снапшоты данных + ЖУРНАЛ действий (аудит)
    guardrails.py      ОГРАНИЧИТЕЛИ автодействий (ROI, лимиты изменений, ДРР, бюджет)
    ai.py              ИИ-слой (Claude API) — «мозг» для SEO и решений
    notify.py          Telegram-алерты
  connectors/
    wb.py / ozon.py    API под конкретного клиента (его токены)
  engine/
    unit_economics.py  расчёт маржи/ROI/цены по методике проекта
  tasks/
    ads.py             реклама: пауза убыточных, снижение ставок (auto)
    pricing.py         цены под целевой ROI в рамках guardrails (auto)
    stock.py           остатки/поставки: прогноз + сигнал (поставка — вручную)
    seo.py             SEO из кластеров (ИИ), публикация по подтверждению
  runner.py            прогон по всем клиентам/задачам
```

## Режимы автоматизации (на клиента, на задачу)

- `auto` — исполняем автоматически **в рамках ограничителей**.
- `suggest` — ИИ готовит, человек подтверждает (для SEO и чувствительных действий).
- `off` — задача выключена.

Ограничители (guardrails) в реестре клиента — автомат не выйдет за них:
не опустит цену ниже ROI, не изменит цену/ставку больше лимита, не превысит рекламный бюджет.
Поставки и публикация SEO по умолчанию идут через подтверждение.

## Аудит

Каждое действие ИИ пишется в `db.actions` (клиент, задача, SKU, что сделано, статус, результат,
время). Это защита: всегда видно, кто и что менял — критично при работе на чужих магазинах.

## Запуск

```bash
pip install requests python-dotenv pyyaml
cp mp_platform/clients/clients.example.yaml mp_platform/clients/clients.yaml
cp .env.example .env     # вписать токены клиентов и ANTHROPIC_API_KEY

python -m mp_platform.runner all stock      # остатки по всем клиентам
python -m mp_platform.runner korotich ads   # реклама конкретного клиента
python -m mp_platform.runner                 # все клиенты, все задачи
```

## Добавить клиента

1. Блок в `clients.yaml` (id, имена ENV-переменных токенов, режимы, guardrails).
2. Его токены — в `.env` (или в менеджер секретов на сервере).
3. Готово — следующий прогон подхватит нового клиента.

## Сервер (Hetzner, 24/7)

Склонировать в `/opt/k-beauty`, `.venv`, `.env`, `mkdir logs`, затем
`crontab -e` ← строки из `mp_platform/crontab.example`.

## Что доделать под боевой запуск (отмечено TODO в коде)

- `tasks/pricing.py` и `tasks/seo.py` — привязать источник себеса/цен и кластеров клиента.
- Сверить точные пути API (WB «Продвижение»/«Цены», Ozon stocks/prices/поисковые запросы).
- Шифрование токенов (сейчас — ENV; на сервере добавить менеджер секретов).
