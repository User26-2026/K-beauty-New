# Отгрузки в пути

Сюда кладем инвойсы и упаковочные листы по товару, который уже едет.

- `2026-09_container_invoice.xlsx` — инвойс на контейнер 40ft, Корея -> Москва.
- `2026-09_truck_manifest.csv` — товар, который идет машиной. Прайса в
  документе нет, только количество и штрихкоды: цены подтягиваем из
  инвойса и прайсов поставщиков.

Себестоимость до Москвы считаем через `tools/landed_cost.py`: инвойсная
цена плюс процент на растаможку и доставку (для этой поставки 30%).
