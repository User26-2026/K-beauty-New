# Источники по судовому оборудованию

## Учетные файлы склада с ценами (основной источник)

`source/` — девять учетных файлов, по одному на локацию хранения. Это не
прайсы поставщиков, а собственный склад с проставленными ценами продажи.

| Файл | Локация | Итог в файле, руб |
| --- | --- | ---: |
| `garazh_1.xls` | Гараж 1 | 3 320 390 |
| `garazh_2.xlsx` | Гараж 2 | 4 610 000 |
| `konteiner_1.xls` | Контейнер 1 | 797 300 |
| `konteiner_2.xls` | Контейнер 2 | 8 421 000 |
| `sklad_1a_1b.xlsx` | Склад 1А и 1Б | 9 385 550 |
| `sklad_2.xls` | Склад 2 | 9 369 586 |
| `sklad_3.xls` | Склад 3 | 18 638 516 |
| `menedzherskaya.xls` | Менеджерская | 11 799 500 |
| `foye.xls` | Фойе | 26 628 726 |

Раскладка колонок у файлов разная, поэтому она задана явно в
`workspace/marine_equipment/build_marine_registry.py`. Пересчет реестра
сходится с «ИТОГО» каждого файла до рубля — это контроль разбора.

Общее по девяти файлам: 596 позиций в наличии, 11 029 единиц,
92 970 568 руб по указанным ценам.

Колонка «кол-во по учету» — данные инвентаризации 24.08.2023,
колонка «наличие» — что осталось после отгрузок на 16.06.2025.
В реестре считаем по наличию.

### Чего в этих файлах нет

Нет локации «улица». Там лежат брашпили Б3 и Б4, лебедки ЛЭ74,
подруливающие устройства ПУ-130, кран-балка, блок цилиндров NVD48A2U,
трал ЛЭТРС-2, насос НЦВП 315/10. Цен по ним нет ни в одном файле,
при этом брашпили Б3/Б4 спрашивал покупатель из Нижнего Новгорода.
