# Помесячные P&L отчёты Ракеты (правильный формат)

Настоящие месячные выгрузки P&L по SKU из Ракеты (формат 1С, лист `TDSheet`).
В отличие от «по складам» рекламных выгрузок — здесь ЕСТЬ продажи/выручка/маржа.

## Структура файла
- Строка 0: месяцы (`Январь 2025`, `Февраль 2025`, …, `Итого`)
- Строка 1: типы колонок (ABC / Показатель / Показ-ль %)
- Каждый SKU = 3 строки: `Заказы` / `Выручка на р/с` / `Маржа`
- Колонка `Показатель` (месяц_col+1) = само число
- Колонки: 0=Артикул ВБ, 1=Артикул поставщика(название), 2=Тег, 3=Фото

## Именование
`raketa_pnl_<месяц>_2025.xlsx` — по месяцам.

## Важно
- Колонка «Заказы, шт» часто пустая → сезонность считаем по ВЫРУЧКЕ.
- Непрофиль (скалеры/роботы/рации) фильтровать при анализе косметики.
