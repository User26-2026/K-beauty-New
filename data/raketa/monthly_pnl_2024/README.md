# Помесячные P&L отчёты Ракеты за 2024 год (правильный формат)

Настоящие месячные выгрузки P&L по SKU из Ракеты (формат 1С, лист `TDSheet`),
с заполненными продажами/выручкой (1 строка на SKU, 146 колонок).

## Ключевые колонки (индекс с 0)
- 0 Артикул ВБ, 1 Артикул поставщика(название)
- 10 Количество заказано ЛК, шт
- 15 С СПП. Продажи, шт | 17 С СПП. Сумма продаж, руб
- 30 (AE) К нам. Продажи - возвраты, руб (М)

## Именование
`raketa_pnl_<NN>_<месяц>_2024.xls`

## Важно
- Сезонность считать по ЗАКАЗАМ (штукам), не по выручке.
- Непрофиль (скалеры/роботы/рации) фильтровать при анализе косметики.
