# Прайсы поставщика G&E Global (Корея)

Компания-поставщик в Корее, менеджер — Инна. Присланные ею файлы приходят
с именами, начинающимися на «Инна», — по этому признаку и опознаем прайсы
этого поставщика.

## Именование файлов

```text
ge_global_<бренд-или-all>_<ГГГГ-ММ-ДД>.<xlsx|csv>
```

Исходное имя от менеджера сохраняем внутри, если по нему нужно будет
найти письмо.

## Что уточнить по этому поставщику

- Валюта прайса (KRW / USD / RUB).
- Базис цены: FOB Корея или уже с доставкой до РФ. От этого зависит,
  применять ли множитель 1.4 при расчете себестоимости.
- MOQ по SKU и минимальная сумма заказа.
- Есть ли скидки от объема и уровни цен.
- Ограничения по рынкам: эксклюзивы на Россию, запрещенные страны.

## Как обрабатываем

```bash
python3 tools/import_uploads.py <папка_загрузок> ge_global
python3 tools/parse_price_lists.py --rate 0.058
python3 tools/compare_suppliers.py --min-diff 5
```

Сравнение с Классиком и прямыми прайсами брендов ляжет в
`outputs/supplier_price_comparison.xlsx`.
