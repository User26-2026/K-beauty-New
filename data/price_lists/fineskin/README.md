# Прайсы поставщика FINESKIN (Корея)

Компания-поставщик в Корее. Прайсы приходят по одному файлу на бренд,
имя файла — название бренда.

## Именование файлов

```text
fineskin_<бренд>.<xlsx|csv>
```

Даты в именах поставщик не ставит, поэтому дату прайса фиксируем в журнале
прайсов при получении.

## Что уточнить

- Валюта прайса и базис поставки. НДС не спрашиваем: корейские прайсы
  идут на экспорт и всегда без НДС.
- MOQ по SKU и минимальная сумма заказа.
- Уровни цен по объему заказа.
- Ограничения по рынкам: эксклюзивы на Россию, запрещенные страны.
- Закупает напрямую у правообладателя бренда или через посредника.

## Как обрабатываем

```bash
python3 tools/import_uploads.py fineskin <файлы>
python3 tools/parse_price_lists.py
python3 tools/compare_brand.py DR.ALTHEA --min-diff 5
```
