# Прайсы поставщика GlowBeauty (Корея)

Компания-поставщик в Корее, менеджер — Асель.

## Именование файлов

```text
glowbeauty_<бренд-или-all>_<ГГГГ-ММ-ДД>.<xlsx|xls|csv>
```

Старые версии прайсов не удаляем: по ним смотрим динамику закупочной цены.

## Что уточнить по этому поставщику

- Валюта прайса (KRW / USD / RUB).
- Базис цены: FOB Корея или уже с доставкой до РФ. От этого зависит,
  применять ли множитель 1.4 при расчете себестоимости.
- MOQ по SKU и минимальная сумма заказа.
- Есть ли скидки от объема и несколько уровней цен.
- Ограничения по рынкам: эксклюзивы на Россию, запрещенные страны.

## Как обрабатываем

```bash
python3 tools/import_uploads.py glowbeauty <папка_загрузок_или_файлы>
python3 tools/parse_price_lists.py --rate 0.058
python3 tools/compare_suppliers.py --min-diff 3
```

Сравнение с Классиком, G&E Global и прямыми прайсами брендов ляжет в
`outputs/supplier_price_comparison.xlsx`. Товары сопоставляются по
штрихкоду — названия у поставщиков расходятся.
