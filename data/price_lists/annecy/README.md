# Прайсы поставщика Аннеси (Annecy, Корея)

Компания-поставщик в Корее. Сайт: https://annecy.kr

## Именование файлов

```text
annecy_<бренд>_<ГГГГ-ММ-ДД>.<xlsx|xls|csv>
```

Свои файлы поставщик присылает с датой в начале имени: `260810_LAMELIN_LIST`
— это 2026-08-10. При импорте имя сохраняем как есть, дата разбирается
скриптом реестра.

## Что уточнить по этому поставщику

- Валюта прайса (KRW / USD / RUB).
- Базис цены: FOB Корея или уже с доставкой до РФ. От этого зависит,
  применять ли множитель 1.4 при расчете себестоимости.
- MOQ по SKU и минимальная сумма заказа.
- Есть ли скидки от объема и несколько уровней цен.
- Ограничения по рынкам: эксклюзивы на Россию, запрещенные страны.
- Закупает напрямую у правообладателя бренда или через посредника.

## Как обрабатываем

```bash
python3 tools/import_uploads.py annecy <папка_загрузок_или_файлы>
python3 tools/parse_price_lists.py --rate 0.058
python3 tools/compare_brand.py MEDIPEEL --min-diff 5
```
