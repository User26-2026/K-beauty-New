# Прайсы поставщика Классик (Корея)

Сюда складываем все прайсы поставщика, которого мы называем **Классик**.
Каждый следующий поставщик получает свою папку рядом: `data/price_lists/<имя>/`.
Файлы, лежащие прямо в `data/price_lists/`, считаются прямыми прайсами брендов.

## Именование файлов

```text
classic_<бренд-или-all>_<ГГГГ-ММ-ДД>.<xlsx|pdf|csv>
```

Примеры:

- `classic_all_2026-08-21.xlsx` — общий прайс по всем брендам.
- `classic_anua_2026-08-21.xlsx` — прайс только по одному бренду.

Старые версии не удаляем: по ним смотрим динамику закупочной цены.

## Даты в именах файлов Классика

Классик ставит в имя файла две цифры года и месяц: `26.05` — май 2026,
`26.08` — август 2026. Исключение — `AMORE_PACIFIC_PRICE_LISTVAT_25.10`:
это действующий прайс 2026 года, подтверждено поставщиком. Так что дату
прайса берем из журнала, а не из имени файла.

## Что фиксируем по каждому прайсу

- Валюта прайса (KRW / USD / RUB).
- Базис подтвержден: EXW, самовывоз со склада поставщика.
- Базис цены: FOB/ex-works (тогда сверху множитель 1.4 на логистику,
  пошлину и приемку) или уже с доставкой до РФ.
- MOQ по SKU и минимальная сумма заказа.
- Дата прайса и срок действия цен.

## Как считаем себестоимость

1. Если товар есть в `data/stock_costs/ОСТАТКИ_КОРЕЯ_03.06.xlsx` —
   приоритет у желтой колонки `Себестоимость по последнему приходу`.
2. Если товара в остатках нет — считаем из прайса:

   ```text
   себестоимость_руб = цена_в_валюте * текущий_курс_к_рублю * 1.4
   ```

3. Берем закупочную цену (`SUPPLY PRICE (-VAT)` / `FOB PRICE (KRW/-vat)`),
   не MSRP.

## Как обрабатываем

```bash
python3 tools/import_uploads.py <папка_загрузок> classic
python3 tools/parse_price_lists.py --rate 0.058
python3 tools/compare_suppliers.py --min-diff 5
```

Результаты в `outputs/`: `prices_normalized.xlsx` — все SKU всех поставщиков,
`supplier_price_comparison.xlsx` — где один и тот же товар дешевле.

Сопоставление товаров между поставщиками идет по штрихкоду, а где его нет —
по нормализованному названию с объемом. Если штрихкод совпал, а названия
разные, пара помечается `Проверить: штрихкод у разных товаров` — в прайсах
встречаются чужие штрихкоды.
