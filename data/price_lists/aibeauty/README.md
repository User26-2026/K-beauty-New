# Прайсы поставщика Aibeauty (Дордой, Бишкек, Киргизия)

Прайс приходит в PDF, тремя файлами подряд: страницы 1-10, 11-20 и 21-30
одного и того же документа. Валюта — доллары, курс в прайсе 88 сом за
доллар, дата цен 04.08.2026.

Бренд у них написан прямо в названии в скобках: «(Anua) Крем для лица…».

## Именование файлов

```text
aibeauty_<ГГГГ-ММ-ДД>_p<страницы>.pdf
aibeauty_<ГГГГ-ММ-ДД>_p<страницы>.csv
```

## Как обрабатываем

```bash
python3 tools/pdf_price_to_csv.py <файл>.pdf <файл>.csv
python3 tools/parse_price_lists.py
```

Во втором и третьем файле шапки нет — прайс начинается сразу со строк
товара. Раскладку колонок разборщик определяет по данным.

## Что уточнить

- Базис: цены со склада на Дордое или с доставкой.
- Минимальная сумма заказа и условия оплаты.
- Полный прайс одним файлом, а не тремя кусками.

## Важно

Киргизия — не канал поставки, а ориентир по цене.
