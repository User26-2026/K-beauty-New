# Подключение по API: Wildberries и Ozon

Как получить доступ к кабинетам по API и в чём разница между площадками.

---

## WILDBERRIES

### Как получить доступ
1. Кабинет продавца → **Настройки → Доступ к API** (Профиль → Настройки → Доступ к новому API).
2. Создать токен, отметить галочками нужные **категории доступа**.
3. Скопировать токен **сразу** (показывается один раз).

### Аутентификация
- **Один токен** (длинная строка — JWT) на все категории.
- Передаётся в заголовке: `Authorization: <токен>` (**без слова Bearer**).
- У токена есть срок жизни (обычно до ~180 дней) и привязка к категориям.

### Категории (галочки при создании токена)
| Категория | Что даёт | Хост API |
|---|---|---|
| Статистика | продажи, заказы, остатки (история) | `statistics-api.wildberries.ru` |
| Маркетплейс | поставки, склады, FBO/FBS | `marketplace-api.wildberries.ru` |
| Контент | карточки (чтение/запись названий, описаний) | `content-api.wildberries.ru` |
| Аналитика | воронка, хранение, платная приёмка | `seller-analytics-api.wildberries.ru` |
| Продвижение | реклама: кампании, ставки, статистика | `advert-api.wildberries.ru` |
| Цены и скидки | изменение цен | `discounts-prices-api.wildberries.ru` |

**Особенность WB:** один токен, но **разные хосты (базовые URL) под каждую категорию**.
То есть реклама идёт на `advert-api...`, цены — на `discounts-prices-api...`, с тем же токеном.

### Лимиты
- Жёсткие лимиты по частоте запросов на каждый метод (например, статистика — 1 запрос в минуту на некоторые отчёты). При 429 — ждать и повторять с паузой.

## OZON

### Как получить доступ
1. Кабинет продавца → **Настройки → Seller API** (API-ключи).
2. Сгенерировать **Api-Key**, выбрать роль (Admin / только чтение и т.п.).
3. Там же виден **Client-Id** (номер клиента).

### Аутентификация
- **Два значения:** `Client-Id` (номер) + `Api-Key` (ключ).
- Передаются **двумя заголовками**:
  ```
  Client-Id: <номер>
  Api-Key: <ключ>
  ```
- **Один базовый хост** на всё: `https://api-seller.ozon.ru`.
- Можно создать **несколько ключей** с разными ролями (удобно для сервиса: отдельный ключ только на чтение).

### Основные разделы (один хост, разные пути)
| Что | Путь (пример) |
|---|---|
| Товары | `/v3/product/list`, `/v3/product/info/list` |
| Остатки | `/v4/product/info/stocks` |
| Цены | `/v1/product/import/prices` |
| Аналитика | `/v1/analytics/data` |
| Заказы FBO/FBS | `/v2/posting/fbo/list`, `/v3/posting/fbs/list` |

### Реклама Ozon — отдельный API (важно!)
Реклама на Ozon **НЕ** в Seller API. Это отдельный **Performance API**:
- Хост: `https://api-performance.ozon.ru`
- Авторизация **другая**: OAuth — `Client-Id` + `Client-Secret` → получаешь временный **Bearer-токен**, им подписываешь запросы рекламы.
- То есть для рекламы Ozon нужна **отдельная пара ключей** (из раздела «Продвижение → API»).

## В ЧЁМ РАЗНИЦА (коротко)

| Параметр | Wildberries | Ozon |
|---|---|---|
| Что за ключ | **1 токен** (JWT) | **2 значения:** Client-Id + Api-Key |
| Заголовок | `Authorization: <токен>` (без Bearer) | `Client-Id:` + `Api-Key:` (два заголовка) |
| Базовый URL | **разные хосты** под каждую категорию | **один хост** `api-seller.ozon.ru` |
| Разграничение прав | галочки-категории при создании токена | роль у каждого Api-Key + можно много ключей |
| Реклама | тот же токен, хост `advert-api...` | **отдельный Performance API** (OAuth, свой Bearer) |
| Срок жизни ключа | ограничен (~180 дней), надо обновлять | ключ живёт, пока не отозван |
| Лимиты | жёсткие, пометодно (бывает 1 запрос/мин) | мягче, но тоже есть |

### Главные отличия словами
1. **WB — один ключ, много хостов.** Создаёшь один токен с галочками, но стучишься на разные адреса (реклама, цены, статистика — разные базовые URL).
2. **Ozon — пара ключей, один хост,** но **реклама отдельно** через Performance API со своей OAuth-авторизацией.
3. **WB-токен надо обновлять** (истекает), Ozon-ключ живёт до отзыва.
4. У **Ozon удобнее разграничение** — можно отдельный ключ «только чтение» (безопаснее для сервиса/подрядчика).

## Как это заложено в нашу платформу

- `.env` хранит: `WB_TOKEN_<клиент>`, `OZON_CLIENT_ID_<клиент>`, `OZON_API_KEY_<клиент>`
  (+ для рекламы Ozon позже добавим `OZON_PERF_CLIENT_ID/SECRET`).
- Коннекторы:
  - `mp_platform/connectors/wb.py` — один токен, методы бьют в нужный хост (advert/discounts/content/statistics).
  - `mp_platform/connectors/ozon.py` — пара Client-Id/Api-Key, один хост; для рекламы добавим отдельный модуль Performance API.
- Токены **никогда не в чат и не в git** — только в `.env` (или в менеджере секретов на сервере).

## Что нужно от тебя для подключения
**Wildberries:** создать токен с галочками (минимум: Статистика, Аналитика, Продвижение, Цены и скидки, Контент) → вписать в `.env` как `WB_TOKEN_KOROTICH` (и отдельный для Кроны).

**Ozon:** в Seller API создать Api-Key → вписать `OZON_CLIENT_ID_...` и `OZON_API_KEY_...`.
Для рекламы Ozon — отдельно пару из раздела «Продвижение → API».

> Важно: токены не присылай в чат. Они живут только в `.env` на твоей машине/сервере.
