# Регламенты магазина корейской косметики на Wildberries

Свод внутренних регламентов для сотрудников магазина. Каждый регламент —
это обязательный порядок действий. Если в процессе появляется ситуация, не
описанная регламентом, сотрудник фиксирует ее и передает руководителю, чтобы
дополнить документ.

## Как пользоваться

- Регламент читается сверху вниз, разделы не пропускаются.
- Все числовые пороги (ДРР, CPO, локальность и т.д.) — рабочие ориентиры
  магазина. Менять их можно только через руководителя, а не «на глаз».
- Расчеты юнит-экономики и фактической прибыли ведем по логике из `CLAUDE.md`
  и файла `data/unit_economics/Celimax_unit_model.xlsx`.
- Любое решение по ставке, ключу или бюджету должно опираться на цифры из
  отчетов WB и MP Manager, а не на ощущения.
